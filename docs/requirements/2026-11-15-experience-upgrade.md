# 需求：Billow 体验升级

日期：2026-11-15

本文件补充 `2026-11-15-ui-redesign.md` 与 `2026-11-14-mihomo-desktop-android-client.md`。与两份文件冲突时以本文为准；未提到的行为与失败边界保持不变。

## 一屏摘要

- 目标：在现有 Billow 上完成一次以日常使用效率为中心的体验升级，保留既有功能边界，新增 R23–R31 与 R33。
- 使用者：已有 Mihomo 订阅或本地配置的桌面与 Android 用户；不提供节点、订阅、账号或云同步服务。
- 范围：视觉系统与信息密度、首页首屏、导航与命令、代理/配置/连接/规则/日志/资源页、代理组图标、反馈与恢复、无障碍、性能边界。
- 关键行为：首页只保留一个连接主操作；手机首屏完成状态与网络接管，模式紧随其后；桌面侧栏分组并提供 Ctrl/Cmd+K 命令面板；代理页首次进入展开当前组；配置编辑有未保存保护；连接详情实时更新；规则显示命中并可临时禁用；日志可复制与导出；配置声明的代理组图标在组头显示并在缺失或失败时回退（R24–R30、R33）。
- 成功标准：390px 宽度首屏可见状态、当前配置、唯一主操作与网络接管；浅深主题正文达到 WCAG 2.2 AA 对比度；键盘可完成导航、搜索、选择节点与关闭弹层；大列表滚动与筛选不失位；带图标代理组不破坏组头布局；R1–R7、R16–R22 的失败边界不回退（R23–R31、R33）。
- 不做事项：不增加 WebDAV、Sub-Store、请求或 DNS 明细、载荷查看、全局热键、快捷磁贴、Android TV、主题市场、CSS 注入、云账号与遥测（R32）。
- 假设：保留 Billow 名称、蓝色强调色、现有 5 个移动主入口和桌面 8 个入口；桌面入口改为分组展示，不删除入口。

## 完整需求

### R23 视觉系统与信息密度

行为：界面使用同一套颜色、字号、间距、圆角和动效 token。正文分主文字、次文字、弱文字三级；弱文字在两套主题的页面底色和内容底色上都可读。卡片只包裹真正相关的内容，同类数据优先用列表行表达；桌面使用紧凑密度，手机使用舒适密度。主按钮、分段选项和选中行使用同一圆角值；同一层级不出现多种强调色、毛玻璃叠层或多层装饰阴影。速率、延迟、流量等数字继续使用等宽数字。页面切换、折叠和弹层使用短促过渡，系统要求减少动态效果时停止装饰动画。

适用与失败边界：适用于全部页面和弹层。弱文字在任一主题下对比度不足时，该文字视为不可读，不能以字号小或“只是辅助信息”为由保留。不得为了填满卡片制造空图表、空统计或无内容区域。品牌标识、流量进度条和延迟状态可以使用强调色或轻渐变，除此之外不使用装饰性渐变背景。

验收：

- 浅色和深色主题下，12–14px 的正文、说明和状态文字对所在底色达到至少 4.5:1；图标、边框和焦点环达到至少 3:1
- 主按钮、分段选项和节点选中行的圆角一致；除延迟绿/黄/红和成功/失败语义色外，强调色只有一种；除品牌标识和流量进度条外没有渐变背景
- 390px 宽度下模式选择不出现三列文字换行，320px 宽度下页面没有横向滚动，标题、标签和数字不被截断
- 系统开启减少动态效果时，没有持续循环的装饰动画；普通过渡不超过 200ms，且不阻塞状态文字和操作结果
- 速率和延迟数字位数变化时，所在列不左右跳动；桌面卡片高度由内容决定，不因固定高度出现空白，也不靠缩小字号提高同屏数量

### R24 首页首屏与连接操作

行为：首页从上到下先给结论再给细节。手机 390×844 的首屏内可见状态词、当前配置、唯一连接主操作和网络接管摘要；已连接时同时可见上传与下载速率。桌面把状态、主操作、模式和接管放在主列，把流量、当前节点和订阅放在次列。连接主操作是一个整体控件，电源图标与“连接”“断开”“添加配置”文字属于同一个按钮，不再另放第二个同义主按钮。手机的模式选择改为单行分段控件，当前模式的一句说明显示在控件下方；桌面的模式卡片保留逐项说明。网络接管保持系统代理与 TUN 两个桌面开关；Android 保持 VPN 与分应用代理。已连接时显示运行状态：内核版本、内核内存、运行时长、活动连接数；内核未提供内存或运行时长时隐藏对应项，不显示占位数字。当前节点区列出可手动选择的组；数量过多时显示“查看全部”进入代理页。订阅区保留流量进度、到期时间、更新时间和更新动作。

适用与失败边界：没有配置时只显示欢迎、添加配置和导入说明，不显示模式、接管、流量统计或伪造的订阅数据。连接失败、接管失败或模式切换失败时，失败原因留在首页顶部，并提供“重试”和“查看日志”；成功后或下一次主动尝试后按既有规则更新。连接中再次点击主操作不启动第二套内核。断开后速率消失，但当前配置、模式和接管开关保持可见。内核未运行时，运行状态项隐藏或不显示数字，不能把上一拍数据当作实时数据。

验收：

- 390×844 下不滚动即可看到状态、当前配置、唯一主操作和网络接管；已连接时还看到上传、下载速率
- 首页只有一个控件能触发连接或断开；电源图标与文字属于同一按钮，没有第二个“连接”按钮
- 手机模式选择在一行内显示规则、全局、直连，并显示当前模式的一句说明；桌面仍能看到每种模式的说明
- 没有配置时首页不出现模式和接管，点击添加配置直接打开添加层
- 已连接且内核返回内存时显示内核版本、内存和活动连接数；不返回内存时不显示该项，且不出现破折号占位
- 连接失败后首页顶部能看到原因、重试和查看日志；重试成功后失败条消失

### R25 导航分组、命令面板与位置恢复

行为：桌面侧栏保留首页、代理、配置、连接、规则、资源、日志、设置，但用“核心”和“工具”两个分组标题分隔前四项与后三项，设置固定在底部；当前项仍用强调色和 `aria-current` 标记。手机底部仍为首页、代理、配置、连接、设置五项，规则、资源、日志从设置页进入。桌面和带键盘的 Android 提供应用内命令面板：Ctrl/Cmd+K 打开，可搜索页面、设置分类和常用动作（连接、断开、全部测速、更新全部订阅、添加配置、切换主题、打开日志）；上下键移动，Enter 执行，Esc 关闭并把焦点还给打开前的控件。提供 `/` 聚焦当前页搜索框、Esc 关闭弹层或清空搜索、`?` 打开快捷键说明。页面记住滚动位置；从首页节点行进入代理页并定位到组后，返回首页恢复原位置。切换页面不阻塞导航，也不在过渡期间丢失当前状态。

适用与失败边界：命令面板是应用内快捷键，不注册全局热键，不在应用外生效。输入框聚焦时，`/` 不抢输入；弹层打开时，快捷键只作用于弹层。命令面板不列出删除配置等不可撤销动作；列出但当前不可执行的动作要显示原因。窗口尺寸变化、页面刷新或应用重启后，无法恢复的滚动位置回到顶部，不阻止进入页面。

验收：

- 桌面侧栏能看到“核心”和“工具”分组标题，入口顺序不变，设置仍在底部；手机底部仍是五项
- 在任意页面按 Ctrl/Cmd+K 打开命令面板，输入“代理”后回车进入代理页，按 Esc 关闭并回到原焦点
- 命令面板中的“全部测速”在未连接时不可执行并显示“连接后可测速”；面板中不存在删除配置
- 在代理页滚动到中部后切到首页再返回，滚动位置保持；从首页进入某个组后能看到该组被定位
- 在搜索框内按 `/` 不会插入字符或跳焦点；关闭弹层后焦点回到打开它的按钮
- 从任意页面切换后当前项标记立即正确，过渡期间不出现空白页或错误页

### R26 代理页浏览与测速效率

行为：首次进入代理页时展开当前手动组；没有当前选择时展开第一个手动组，并滚动到该组。使用者展开或收起过的组在应用重启后仍保留；从首页指定组进入时优先展开并定位该组。工具栏在滚动时保持可见，包含搜索、匹配数量、排序、隐藏自动组、紧凑视图和展开/收起全部。组头显示组类型、当前节点、节点数、当前节点延迟和最近一次测速结果；自动组显示当前节点但不能手选。全部测速显示“已测/总数”进度，节点逐个出现结果；单个失败只把该节点标为“超时”，已成功结果保留。搜索命中时高亮匹配文字并显示“匹配 N 个节点”；无命中时提供清空搜索。节点行整行可选择，测速按钮是独立的同级按钮；自动组节点可见但不可选。键盘可用 Tab 到达节点行，Enter 或空格选择。

适用与失败边界：内核未运行时，测速按钮不可用并显示“连接后可测速”，不能只靠悬停提示。搜索只过滤视图，不改写已保存的节点选择。切换排序只改变当前页显示，不写回配置。组展开状态损坏或引用的组不存在时，回到默认展开第一个手动组，不阻止页面显示。节点很多时不一次性展开全部节点。

验收：

- 首次进入代理页能看到当前组已展开，其他组保持收起；再次进入沿用上次展开状态
- 从首页点“流媒体”组后进入代理页，该组展开并滚动到可见位置
- 全部测速时显示已测数量和总数，失败节点显示“超时”，其他节点结果仍在
- 搜索“新加坡”后只显示匹配节点并显示匹配数量；清空搜索后恢复原列表
- 自动组的节点行点击不改变当前节点；手动组节点行按 Enter 后变为当前选择
- 390px 宽度下工具栏不横向溢出，滚动时搜索和排序仍可见

### R27 配置页编辑安全与批量更新

行为：配置页保持当前配置置顶和卡片网格，但卡片按内容收紧，不再用固定高度留出空白。快速导入在输入已存在的订阅链接时提示“该订阅已存在”，并把焦点移到已有卡片，不静默新增重复项。全部更新显示“正在更新 x/y”，每个卡片独立显示更新中、成功或失败；失败原因留在对应卡片上并提供重试。编辑配置文件或覆写时，行号栏与正文同步滚动；有未保存修改时关闭弹层先确认是否放弃，取消后保留编辑内容和光标位置；保存失败时错误紧贴编辑器显示，弹层不关闭。操作菜单支持 Esc 关闭、上下键移动和焦点回到触发按钮。

适用与失败边界：订阅更新中关闭页面不丢失已开始的更新；重新进入仍能看到结果或失败。订阅更新会覆盖手动编辑的正文，因此正文编辑器继续提示长期修改应使用覆写；该提示不改变已有保存行为。订阅链接不可取回、YAML 无法应用或保存失败时，原配置和已生效内容保持不变，错误必须可见。删除配置仍需确认；确认前不删除本地文件。

验收：

- 修改 YAML 后直接关闭弹层会出现放弃确认；取消后编辑器内容、光标和未保存标记仍在
- 编辑器滚动到底部时行号与正文仍对齐；保存失败时错误显示在编辑器下方且弹层保持打开
- 导入一个已存在的订阅链接时出现“该订阅已存在”，已有卡片获得焦点，配置数量不增加
- 全部更新时看到 x/y 进度；其中一个失败时该卡片保留失败原因，其他卡片仍显示成功
- 操作菜单按 Esc 关闭后焦点回到“更多操作”按钮；用键盘上下键能移动到菜单项
- 390px 宽度下配置卡片内容不被截断，当前配置仍在第一张

### R28 连接、规则、日志与外部资源诊断

行为：连接详情跟随最新采样更新上传、下载、时长和代理链；连接在详情打开时被关闭，详情显示“已断开”并禁用断开按钮。详情提供复制摘要，内容至少包含主机、进程、规则、代理链、上传、下载和持续时间。暂停连接列表时同时冻结总数和累计流量，显示暂停时刻和“N 条新连接”；重新继续后追上最新状态。手机连接卡片同时显示上传、下载和时长，不只显示下载。规则页在接口返回命中信息时显示命中次数、最后命中时间和规则条目数量；可按命中次数排序、按类型或策略筛选，并可临时禁用或启用单条规则，禁用项明显变暗且标注“临时，重启后恢复”。日志暂停时冻结列表和级别计数，显示暂停时刻与新日志数量；单条日志可复制，筛选结果可整体复制或导出，长日志可切换自动换行。外部资源页显示资源类型、来源、格式、条目数、更新时间和到期或流量信息；内联资源标注“无需更新”并禁用更新按钮；单个或全部更新、健康检查显示进行中与结果，失败原因留在对应资源行并可重试。

适用与失败边界：内核未运行或连接为空时，连接页仍区分“未连接”“没有当前连接”“没有匹配的连接”三种状态。规则接口不返回命中字段时，隐藏命中列并说明该内核不提供，不显示 0 或伪造时间；禁用规则失败时保持原状态并显示错误。日志暂停只暂停视图，不清空后台缓冲；清空日志需要确认。连接详情复制失败时提示无法写入剪贴板，不静默失败。外部资源更新或健康检查失败时保留原资源和原更新时间，不在行内显示成功。不提供请求正文、响应正文或 DNS 查询明细。

验收：

- 打开一条连接详情后等待采样，时长和流量继续变化；在别处关闭该连接后，详情显示“已断开”且断开按钮不可用
- 复制连接摘要后粘贴，能看到主机、进程、规则、代理链和上下行累计值
- 暂停连接列表后总数和累计流量不再变化，并显示新连接数量；继续后恢复到最新数量
- 390px 下连接卡片能看到上传、下载、时长，点击后打开详情
- 规则接口带命中字段时能看到命中次数并按命中排序；禁用一条规则后该项变暗并标注临时禁用，再次启用后恢复
- 日志暂停后计数冻结并显示新日志数量；复制单条日志和复制筛选结果都只包含当前筛选内容
- 外部资源页的内联资源显示“无需更新”且更新按钮不可用；远程资源更新时显示进行中，失败后行内保留原因并可重试
- 全部更新资源时显示已完成数量和总数，单个健康检查的结果不改变其他资源的更新状态
- 界面没有请求正文、响应正文或 DNS 查询明细入口

### R29 加载、反馈与错误恢复

行为：首次加载页面时显示与目标布局一致的骨架，而不是整屏空白加转圈。超过瞬时完成的操作显示具体进度或状态：订阅更新显示 x/y，测速显示已测/总数，内核检查显示检查中，保存显示保存中。不可用按钮旁显示可见原因，触屏也能看到，不只依赖 `title`。错误同时出现在动作附近和必要时的提示条中；动作附近提供重试或关闭。空状态区分加载中、没有数据、没有匹配和读取失败，并给出下一步动作。不可撤销操作的确认与保留结果见 R27、R28；其他破坏性操作也需要确认。成功操作给出简短反馈，失败不能只写入控制台。

适用与失败边界：操作在 1 秒内完成时不闪烁骨架；超过 1 秒才显示进度反馈。批量操作部分失败时保留成功结果，并汇总失败数量。后端不可用或读取快照失败时，页面显示可重试的错误状态，不把上次数据当作最新状态继续展示。提示条不遮挡主操作，移动端不覆盖底部导航。确认层关闭后焦点回到原操作。

验收：

- 首次进入页面看到与页面结构一致的骨架，不出现整屏空白的转圈
- 全部测速和全部更新显示当前进度；完成后显示成功与失败数量
- 未连接时“全部测速”按钮旁能看到“连接后可测速”，不需要悬停
- 更新失败时卡片和提示条都能看到原因，卡片提供重试；其他成功卡片不退回未更新状态
- 搜索无结果、未连接、没有当前连接和读取失败四种空状态文案不同，且各自给出下一步动作
- 删除配置、清空日志、关闭有未保存修改的编辑器都会先确认；取消后数据不变
- 后端读取失败时页面显示错误与重试按钮，不继续显示旧的成功状态

### R30 无障碍、输入与跨平台边界

行为：弹层打开后把焦点移入并限制在弹层内，Esc 关闭，关闭后焦点回到触发控件；弹层有可读标题并阻止背景滚动。组头与测速按钮、节点行与测速按钮是各自独立的焦点目标，不把按钮嵌在另一个按钮或带按钮角色的元素里。所有图标按钮有可读名称，开关有开/关状态，提示与错误使用合适的 live region。桌面可用键盘完成导航、搜索、选择节点、切换开关和关闭弹层；焦点环在所有背景上可见。移动端主要操作目标至少 44×44 CSS px，其他目标至少 24×24 CSS px 且不相邻误触；底部导航避开安全区。Android 返回键先关闭弹层或菜单，再返回上一页。系统要求减少动态效果时，过渡和装饰动画停止，但状态文字和操作结果保留。

适用与失败边界：适用于桌面和 Android。鼠标悬停才出现的信息必须在键盘聚焦时也可见。不能只靠颜色表达连接状态、延迟成功或失败；延迟失败继续显示“超时”文字。屏幕阅读器读取列表时，应能知道当前项、选中项和禁用原因。键盘快捷键不得拦截输入框中的正常输入。

验收：

- 打开弹层后按 Tab 只在弹层内循环，按 Esc 关闭并回到打开它的按钮；背景页面不滚动
- 用键盘从侧栏进入代理页、搜索节点、选择节点、打开连接详情并关闭，全程不需要鼠标
- 组头的展开按钮和组内测速按钮是两个独立焦点；节点行和节点测速按钮也是两个独立焦点
- 所有图标按钮都有可读名称；开关有开/关状态；失败提示被屏幕阅读器读出
- 390px 下主要按钮和开关的可点击区域不小于 44×44 CSS px，相邻开关不会误触
- 系统减少动态效果时，没有循环动画，仍能读到“连接中”“已连接”“超时”等文字
- Android 返回键先关闭打开的分应用弹层或菜单，再离开当前页

### R31 大数据量与性能边界

行为：连接、规则和日志使用增量更新或虚拟滚动，避免每秒重绘全部行。日志追加不改变用户当前滚动位置；筛选、排序、暂停和恢复保持可用。后台标签页或窗口隐藏时暂停轮询，恢复可见后追上最新状态。速率、延迟和流量变化不导致布局抖动；骨架、列表和详情在数据到达时平滑替换。配置和节点数量增加时，页面仍能在 1 秒内响应搜索、排序和展开操作。

适用与失败边界：数据量超过屏幕可显示数量时仍能滚动和筛选；不要求一次性渲染全部行。内核重启或连接清空时，列表回到对应空状态，不保留已失效的行。性能优化不改变 R1–R7 的持久化、失败和生效边界，也不以省略错误反馈换取速度。

验收：

- 日志达到 1000 条时，滚动、筛选、暂停和复制仍在 1 秒内响应，滚动位置不被新日志拉走
- 连接达到 500 条时，排序、筛选、暂停和打开详情仍可用，详情数值继续更新
- 规则达到 300 条时，搜索和按命中排序仍可用，禁用单条规则不导致整页重新加载
- 窗口隐藏后不再持续请求；恢复可见后数量、速率和连接列表追上最新状态
- 速率和延迟每秒变化时，数字列、卡片高度和工具栏位置不抖动
- 内核重启后，连接页和规则页回到对应的未连接或空状态，不显示上一轮的行

### R33 代理组图标显示

行为：代理页组头和首页当前节点区在配置提供图标时显示该组图标。图标来源是当前配置 `proxy-groups[].icon` 声明的图片地址；组名、组类型和延迟仍以文字显示，图标只作辅助识别，不替代文字。没有 `icon`、地址无效或图片加载失败时显示与组类型匹配的内置图标，不出现空框、破图标记或占位数字。图标尺寸固定，不随组展开、收起、测速或数据刷新改变布局。

适用与失败边界：图标加载失败、离线或地址不可达不影响组展开、节点选择、测速和模式切换，也不产生错误提示条；同一组的展开状态、当前节点与延迟显示保持可用。配置更新后组图标按新配置更新，不残留上一份配置的图标。只渲染 http(s) 与内联图片地址，其他协议按没有图标处理。图标是装饰性内容，不进入焦点顺序，不改变组头展开按钮与测速按钮的独立焦点关系；屏幕阅读器仍以组名识别组。本轮不提供图标上传、编辑或缓存管理入口。

验收：

- 配置中某手动组声明可访问的图片地址时，代理页组头和首页对应组显示该图标，组名与延迟仍可见
- 该组没有 `icon` 时显示内置组类型图标，不出现空框或破图
- 把 `icon` 改为不可达地址后，组头回退内置图标，组仍可展开、测速和选择节点
- 390px 宽度下带图标的组头不换行错位，图标不与组名重叠
- Tab 到组头展开按钮与测速按钮时图标不获得焦点，屏幕阅读器读到的组标识仍为组名
- 更新配置后组头图标按新配置显示，不保留上一份配置的图标
