# Billow 日常操作体验优化需求

日期：2026-11-18 · 基线版本：v0.1.27

## 一屏摘要

- 面向在桌面和 Android 上切换配置、编辑设置和排查连接问题的 Billow 用户。
- P0：首页切换配置时看得到进度和实际生效项；订阅或端口保存失败时可在原处修正并重试（R1–R3）。
- P1：从连接详情查看代理组或规则集后，返回即可继续检查同一条连接（R4）。
- 验收覆盖桌面键盘、深浅主题与 Android 窄屏触控。视觉调整以辨认当前状态、读取错误和完成下一步为准，避免纯装饰性元素（R5）。
- 优先级按误判状态的影响和重复操作的成本拟定。真机软键盘和系统返回行为仍需在实现后验证。

## 完整需求

### R1 首页切换配置时显示实际生效项

用户从首页「切换配置」面板选择另一份配置后，面板保持打开，目标行显示「正在启用」。等待期间保留当前生效项标记，阻止重复提交或并发切换。成功后关闭面板，首页显示实际生效的配置。失败时在目标行展示原因和重试入口，当前项标记以实际结果为准。

验收场景：

- A 生效时选择 B，延迟返回结果并连续点选 B、C。只有一次启用请求；完成前能区分 A 和正在启用的 B。B 成功后，首页显示 B，再次打开面板时 B 为当前项。
- 让 B 启用失败且 A 仍然生效。面板中 A 仍带当前项标记，B 显示原因。修复失败条件后，可就地重试 B 并完成切换。
- 点选已生效的配置时不重复启用，也不出现等待状态。

### R2 订阅编辑失败后保留输入，支持部分保存后的重试

用户在「编辑配置信息」中一次修改多个字段时，提交前按已有字段规则校验整份表单，包括有改动的高级选项。能在提交前发现的错误应定位到字段。提交后若只保存了部分修改，弹窗保持打开，让用户分辨已保存、保存失败和仍待保存的内容。重试时只提交与当前已保存值仍有差异的字段。

验收场景：

- 同时修改名称和订阅链接，链接格式无效时点击保存。两个输入都保留，链接旁出现错误，名称仍是原来的已保存值。若出错字段位于折叠区域，用户能直接看到并编辑该字段。
- 名称和链接均通过表单校验，名称保存成功后模拟链接保存失败，自动更新间隔也仍待保存。弹窗指出各项结果；再次保存只提交链接和待保存的间隔。再次打开配置时，各字段与最后一次成功保存的值一致。
- 保存进行中重复点击或按回车，只执行一轮保存。仅在本次修改全部保存后显示整体成功反馈。

### R3 混合端口无效时可就地修正

用户保存混合端口时，非空值必须是 1–65535 的整数。值无效时保留输入、在端口字段旁说明有效范围，现用设置继续生效。清空端口沿用现有的取消端口覆写行为。

验收场景：

- 已保存端口为 7890，输入 65536 后提交。输入框保留 65536，旁边可读到合法范围，现用端口仍为 7890。直接改为 7891 并成功保存后，错误消失，重新进入设置仍显示 7891。
- 分别以 0 和小数提交，均能在原字段修正。以 1 或 65535 提交可通过范围校验。清空并保存可恢复继承值。

### R4 从代理组或规则集返回时恢复连接排查现场

从连接详情跳到入口代理组或命中的规则集，再沿返回路径回到连接页时，恢复原来的页签、搜索词、出站筛选、排序、列表位置和暂停状态，并重新显示原连接详情。按连接身份恢复，避免同名主机的另一条连接被误认为原记录。

验收场景：

- 筛选主机、调整排序、暂停列表，打开一条连接并查看其入口代理组。期间产生新连接。返回后仍是原连接详情；关闭详情后，原筛选和暂停时的列表位置、内容均保留。用户选择继续刷新后才切回实时列表。
- 在实时列表中打开命中规则集的连接并查看该规则集。返回时，仍活动的连接继续显示实时详情；若期间已结束且有可用记录，显示其最后信息和「已关闭」状态，断开操作不可用。
- 原记录已不可用时，返回带有原筛选条件的列表并说明原因。会话已经断开时显示当前断开状态。即使新会话中出现相同主机，也不打开另一条连接的详情。

### R5 桌面和 Android 上均可辨认状态并完成操作

首页将当前配置、连接状态及是否接管系统流量放在用户作决定的位置。选择面板内将进度或失败原因与目标行对齐，表单内将错误与字段关联。用文字或有明确含义的图标表达状态；颜色只作为辅助。操作名称和结果文案在两端保持一致，流量接管方式按平台实际能力显示。

验收场景：

- 在「内核运行、系统代理与 TUN 均关闭」的桌面场景下，从首页可读出当前配置和系统流量尚未接管。Android 则根据实际 VPN 状态展示接管结果。
- 桌面浅色和深色主题下，仅用键盘走通切换配置、修正并保存、跨页查看并返回。每一步均可看清焦点；切换面板关闭后焦点回到触发入口，表单报错后能到达对应字段。
- 在 390px 宽的 Android 布局下，以长配置名、长错误信息和软键盘展开的表单复验。可辨认目标配置、读全原因，通过触控或滚动抵达保存和重试操作。用系统返回键退出规则集详情并返回连接页，结果符合 R4。
