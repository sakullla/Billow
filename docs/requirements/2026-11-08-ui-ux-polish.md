# 需求：UI/UX 打磨（v0.1.11 之后）

日期：2026-11-08
更新：2026-11-16
追加：R17–R21（效率与一致性）

## 一屏摘要

- 目标：在 v0.1.11 现有设计语言内，修补信息密度、操作可辨识度、视觉噪音与一致性缺口，并让自动策略组（自动、故障转移、负载均衡、智能）可理解（R1–R7、R10–R15）
- 使用者：在桌面端与 Android 上日常切换节点、查看流量与管理规则/配置的 Billow 用户（R1–R7）
- 范围：首页代理组卡片与流量图、代理页工具栏与节点列表、规则行操作、配置卡片对齐、移动端首页状态区、侧边栏状态卡、空状态图标（R1–R7、R10–R15）
- 关键行为：未连接或未测速时不显示伪造延迟（R1）；自动组不单列，但从引用它的条目可查看其策略与成员（R13、R14）；订阅信息伪节点不占节点网格（R11）
- 成功标准：每项在 demo 后端下可按验收复现，并有对应回归测试（R8）
- 新增能力：订阅支持 age 私钥解密（R16）
- 不做事项：不改配色与品牌、不重做整体布局与导航、除 R16 外不加后端接口或 Rust 逻辑、不加装饰性动效（R9）

## 完整需求

### R1 首页代理组卡片显示类型与延迟

行为：首页"代理组"卡片在组名与当前节点之外，显示组类型（手选、自动、故障转移等，与代理页标签文案一致）以及当前节点最近一次测速延迟；延迟颜色分级与代理页节点延迟一致。点击卡片仍进入代理页并定位该组。

适用与失败边界：适用于首页展示的所有代理组。未连接、当前节点从未测速或当前节点为 DIRECT/REJECT 等无延迟数据时显示"—"，不显示 0 ms 或"超时"；测速超时才显示"超时"。

验收：

- demo 后端已连接并执行"全部测速"后，返回首页，每张代理组卡片显示类型标签与延迟数值，数值与代理页同一节点一致。
- 未连接时打开首页，卡片延迟位置显示"—"。
- 点击任一卡片，进入代理页且该组位于可视区域。

### R2 首页流量图冷启动与图例顺序

行为：刚连接、流量采样点不足以形成趋势时，流量图区域显示"正在采集流量…"一类的轻量提示，采样足够后自动切换为曲线；图例顺序与上方速率卡片一致（先下载、后上传）。

适用与失败边界：仅在已连接首页的流量图生效；断开后不显示该提示。重连后重新进入采集提示，不沿用上次会话的曲线。

验收：

- demo 后端点击连接后立即查看首页，流量图显示采集提示而非一条贴底平线；等待采样累积后显示曲线。
- 图例从左到右为"下载""上传"，与速率卡片顺序一致。

### R3 代理页工具栏操作可辨识

行为：代理页的"定位当前节点""紧凑视图""展开/收起全部"在桌面端以图标加文字呈现；开关类操作（紧凑视图）开启时有明显的激活样式和 `aria-pressed` 状态。"展开全部"按当前状态切换为"收起全部"。

适用与失败边界：桌面端（非 compact）展示文字；移动端见 R12。无当前选中节点时，"定位"操作禁用并在提示中说明原因。

验收：

- 桌面宽度下打开代理页，各操作不看提示也能读到文字含义。
- 开启紧凑视图后按钮呈激活样式，读屏属性为已按下；关闭后恢复。
- 所有组已展开时按钮文字为"收起全部"，点击后全部收起且文字变为"展开全部"。

### R4 规则行禁用操作降噪

行为：规则页每行的"禁用"操作在桌面端默认隐藏，鼠标悬停或键盘聚焦该行时显示；移动端以带读屏名称的紧凑图标按钮提供该操作（虚拟滚动列表内弹出菜单会被裁切，故不用菜单）。已禁用的规则整行呈弱化样式并带"已禁用"标记，"启用"操作常驻可见。

适用与失败边界：内核注入、无法禁用的规则仍显示现有说明，不出现可点击操作。操作进行中保持现有"禁用中/恢复中"状态与防重复点击。

验收：

- 桌面端打开规则页，未悬停时各行不显示"禁用"文字；悬停或 Tab 聚焦到某行时出现并可操作。
- 禁用某条规则后，该行弱化并显示"已禁用"与常驻的"启用"按钮。
- compact 宽度下可通过行内图标按钮完成禁用和启用，按钮的读屏名称说明当前动作。

### R5 配置卡片等高对齐

行为：配置页同一行内的配置卡片高度一致，底部元信息（更新时间、节点数、自动更新间隔）贴底对齐；本地文件卡片缺少流量和到期信息时不出现空白占位造成的视觉错位。

适用与失败边界：适用于多列网格布局；单列（compact）布局按内容自然高度排列。

验收：

- demo 后端桌面宽度下，"星河云""备用机场""home-lab.yaml"三张卡高度相同，底部元信息在同一水平线。
- compact 宽度下卡片按内容高度单列排列，无多余空白。

### R6 移动端首页状态表达去重

行为：移动端首页主控区只保留一处连接状态文字（与电源按钮合并或保留大标题之一），仍能区分未连接、连接中、已连接、断开中与连接失败。页面最后一项内容可完整滚动到底部导航栏上方。

适用与失败边界：仅 compact 布局；桌面首页不变。连接失败时状态区需展示错误提示入口，不只回到"未连接"。

验收：

- `?demo=android` 下打开首页，电源按钮附近不再同时出现"连接"标签与"未连接"大标题两处相同含义的文字。
- 点击连接过程中状态文字显示"连接中…"，完成后显示"已连接"。
- 滚动到页面底部，最后一张代理组卡片完整显示在底部导航栏上方。

### R7 空状态图标按语义统一

行为：连接、资源等页面在未连接时的空状态使用与页面含义对应的图标（如连接页用连接图标、资源页用资源图标），不再统一使用通用信息图标；各页的空状态遵循同一规则：页面语义图标表示"尚无内容/未连接"，警示图标仅用于错误。

适用与失败边界：适用于所有使用 `EmptyState` 的页面；错误态仍使用警示图标与 `role="alert"`。

验收：

- 未连接时分别打开连接页与资源页，空状态图标与侧边栏对应导航图标一致。
- 制造读取失败时，空状态显示警示图标而非页面图标。

### R8 一致性、可访问性与回归覆盖

行为：R1–R7、R10–R15 的新增或变更界面在浅色与深色主题下对比度可读，可用键盘完成操作，新增按钮具备可读的 `aria-label` 或文字，并覆盖未连接、加载、无数据、错误等相关边界状态。每项变更新增 Vitest 回归测试，使用 demo 后端与可控计时器。

适用与失败边界：仅约束本需求涉及的界面；不追溯修改无关页面。

验收：

- 浅色与深色主题下逐项检查 R1–R7、R10–R15，无文字不可读或状态无法区分。
- `npm test` 与 `npm run build` 通过，且新增测试分别覆盖 R1–R7、R10–R15 的主要行为与边界。

### R10 侧边栏状态卡高度稳定

行为：桌面侧边栏底部的连接状态卡在未连接、已连接以及速率变化时保持同一高度；已连接时下载/上传各占半行、不换行，使用不超过 6 个字符的紧凑速率（如 `688K`、`1.28M`），悬停提示显示完整速率。

适用与失败边界：仅展开的侧边栏；收起的侧边栏沿用现有提示。速率为空时显示 `—`。

验收：

- 连接后速率在数百 K 与 1M 以上之间波动时，状态卡高度与"设置"入口位置不变，且与未连接时一致。
- 速率文本不出现省略号截断；悬停显示"下载 x KB/s"形式的完整值。

### R11 订阅信息伪节点收为信息行

行为：订阅以节点名夹带的流量、到期、重置等信息（如 `Traffic Reset：17 Days Left`、`4.49 GB | 500 GB`、`剩余流量：…`）不在节点网格中占位，而是在所属组展开后以一行信息标签显示，标签去掉开头的 `【…】` 前缀，悬停可见原名。

适用与失败边界：仅按明确的流量/到期/重置模式识别，普通节点（含"倍率""10Gbps"等字样）不受影响；当前被选中的信息节点和搜索结果仍作为普通行显示，保证可见与可操作。

验收：

- 某组包含上述三类伪节点时，展开后它们只出现在信息行，不出现在节点网格。
- 搜索 `traffic` 时，对应伪节点作为普通行出现。

### R12 手机代理页视图选项带文字

行为：手机端"排序与视图"面板中，排序占一整行；"定位""双列""展开/收起全部"以等宽带文字的按钮排成一行，开启状态有激活样式。

适用与失败边界：仅 compact 布局；文字过长时省略而不换行。

验收：

- 390px 宽度打开面板，三个按钮均可读到文字，排序三项文字居中。

### R13 自动组不单独列出

行为：代理页默认不单列自动组（url-test、fallback、load-balance、smart），也不提供"隐藏自动组"开关；页头组数只统计列出的组，悬停说明另有几个自动组。被深链或从引用条目打开的自动组在本次访问中显示。

适用与失败边界：配置中没有任何手选组时，自动组照常列出，避免空页面。

验收：

- demo 配置打开代理页，看不到"自动选择""故障转移"组卡片与跳转标签，页头显示"5 个代理组"。
- 从首页或条目请求定位"自动选择"时，该组出现并展开。

### R14 自动策略组可理解

行为：手选组中引用自动组的条目显示策略标签与当前指向（如"故障转移 → 香港 01"），并提供进入该策略组的按钮；策略组展开后首行说明选择方式（自动：延迟最低；故障转移：按顺序取第一个可用并自动切回；负载均衡：分摊连接；智能：按历史质量挑选）。故障转移成员按配置顺序显示优先级序号，当前使用者高亮，超时成员的序号标红。首页代理组卡片与主控节点胶囊在当前选择为自动组时显示"自动选择 → 实际节点"。各策略使用可区分的图标。

适用与失败边界：自动组成员仍不可手动切换（沿用现有只读行为）；指向未知时显示"→ 连接后显示"或"→ 等待测速"；嵌套组循环时停止解析。

验收：

- demo 中"节点选择"内"故障转移"条目显示"故障转移 → <当前节点>"，点击箭头后故障转移组出现、展开，显示说明与 1…6 的优先级。
- "自动选择"组说明含"延迟最低"，不显示优先级。
- 在"节点选择"中选中"自动选择"后，首页对应卡片显示"自动选择 → <实际节点>"。

### R15 协议标签简写一致

行为：控制器返回的完整类型名（如 `Shadowsocks`、`ShadowsocksR`）与配置简写使用相同的短标签（SS、SSR）；`smart` 组类型显示为"智能"。

适用与失败边界：未知类型保持原文。

验收：

- 类型为 `Shadowsocks` 的节点标签显示为 SS。

### R16 age 私钥解密订阅

行为：订阅的「编辑配置信息」中可填写 age 私钥（一行一个 `AGE-SECRET-KEY-1…`，`#` 注释行忽略，可多把以便换钥）。更新或启用订阅时，若内容是 age 加密文件（二进制或 ASCII 装甲），用这些私钥解密后再按原流程解析；未加密的订阅不受影响。私钥只保存在本机配置数据中，界面与快照只返回对应公钥（`age1…`）；已配置时显示"已配置 N 个 · 公钥"，可更换或清除。

适用与失败边界：仅订阅类配置。格式错误的私钥不保存并在弹窗内说明；误粘公钥或加密内容时在保存前提示。加密订阅缺少私钥、私钥不匹配、内容损坏分别给出明确失败原因，配置卡片提供"填写私钥/更换私钥"直达入口，打开后聚焦私钥输入框；填写后若此前因 age 失败或从未成功更新，保存后自动重新更新。

验收：

- 用 age 公钥加密的订阅，未填私钥时更新失败并提示需要 age 私钥；填写匹配私钥后更新成功并能解析出配置。
- 填写不匹配的私钥时提示私钥无法解密；`AGE-SECRET-KEY-1` 格式错误时弹窗保持打开并显示格式说明。
- 重启后私钥仍生效；快照 JSON 中不包含私钥原文，只含公钥。
- 清除私钥后再次更新加密订阅，恢复"需要 age 私钥"的提示。

### R17 规则列表列名与策略跳转

行为：桌面端规则列表顶部固定一行列名（序号、类型 · 内容、策略、命中、最近命中），滚动时保持可见；行尾操作列等宽，各行的策略、命中与时间列对齐。策略指向代理组时，策略标签可点击并进入代理页定位该组。手机端不显示列名行，命中次数前带"命中"字样。

适用与失败边界：内核不提供命中信息时不显示命中两列的列名；DIRECT、REJECT 等内置策略和直接指向节点的策略保持纯标签，不可点击。

验收：

- 桌面宽度下打开规则页，不看副标题也能读出每列含义；滚动后列名仍在顶部。
- 点击"节点选择"策略标签，进入代理页且该组可见；DIRECT 标签无点击行为。

### R18 连接页去重与顺序一致

行为：连接页摘要、手机卡片、详情与复制摘要均按"先下载、后上传"排列，与首页和侧边栏一致。桌面端排序只由表头承担，不再同时显示一组重复的排序切换；手机卡片没有表头，保留排序切换。桌面端每行的"断开"按钮默认隐藏，悬停或键盘聚焦该行时显示。

适用与失败边界：触屏（无悬停）的宽屏设备上"断开"按钮常驻；连接详情弹窗内的"断开连接"不受影响。

验收：

- 桌面端连接页工具栏只有搜索框；点击"主机"表头按升序排序。
- 未悬停时行尾无"×"，悬停或 Tab 聚焦该行后出现并可断开。

### R19 首页就地测速

行为：已连接时，首页"代理组"卡片标题栏提供"测速"，测试全部节点并就地刷新各组延迟；测速中按钮禁用并显示"测速中"。

适用与失败边界：未连接或没有手选组时不显示该按钮；结果提示沿用"全部测速"的汇总。

验收：

- 连接后点击"测速"，无需离开首页，代理组卡片的"—"变为延迟数值或"超时"。

### R20 页面切换快捷键

行为：`Ctrl/⌘ + 1…7` 按侧边栏顺序切换首页、代理、配置、连接、规则、资源、日志，`Ctrl/⌘ + ,` 打开设置；快捷键说明列出这两项，侧边栏各项的悬停提示带对应按键。

适用与失败边界：弹窗、命令面板等弹层打开时不响应；浏览器预览中数字键可能被浏览器占用，以桌面应用为准。

验收：

- 按 `Ctrl/⌘ + 2` 进入代理页，`Ctrl/⌘ + ,` 进入设置；命令面板打开时按 `Ctrl/⌘ + 1` 页面不变。

### R21 手机导入框提示精简

行为：手机端配置页的快速导入框提示为"粘贴订阅链接"，不再出现被截断的回车与拖拽说明。

验收：

- 390px 宽度下提示文字完整显示。

## 不做事项

### R9 不扩大到视觉重构与后端变更

行为：不更换配色、字体与品牌元素，不重做整体布局与导航结构，不加入纯装饰性动效；除 R16 的 age 私钥（新增 `set_profile_age_key` 命令与订阅解密）外，不新增后端接口或修改 Rust 逻辑。

适用与失败边界：R1–R7 所需数据均来自现有前端快照；若某项确需后端数据，应暂停该项并另行澄清，而不是在本需求内扩展后端。

验收：

- 除 R16 所需的 `src-tauri/src/age_key.rs`、订阅解密与命令注册外，`src-tauri/` 无其它业务改动。
- 主题色变量与导航结构与 v0.1.11 一致。
- 自动组、伪节点与策略说明均由前端根据现有节点快照推导，未新增接口字段。
