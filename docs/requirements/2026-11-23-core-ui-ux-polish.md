# 需求：核心日常链路 UI/UX 与配色体系优化

日期：2026-11-23

## 一屏摘要

面向 Billow 桌面端（Windows / macOS / Linux）与 Android 日常使用者，在现有前端架构与「碧潮」4.0 体系上，深耕「首页 / 代理 / 配置」三大核心视图、全局壳层与 6 套配色体系，提升视觉质感、交互流畅度、操作效率与边界状态清晰度（R1–R7）。
范围涵盖首页总控与配置/节点快捷弹窗（R1–R2）、代理页筛选与移动端模式切换（R3）、配置导入统一与批量更新反馈（R4）、命令面板/侧栏/可交互 Toast（R5）、核心页面视觉层级与边界态一致（R6），以及 6 套配色明暗精调与色值同步（R7）。
改动限定在前端交互、视觉令牌与轻量本地偏好持久化（`localStorage`，不可用时降级为内存默认值），不改动 Rust 内核与 IPC 协议，不重构排障工具页，不做无意义装饰（R8）。
成功标准：R1–R7 所有关键交互流、边界状态、桌面与移动端视口及配色同步均满足可观察验收，且通过 Vitest 回归测试与前端类型构建校验。

## 完整需求

### R1 首页总控与未接管态直达修复

行为：
- 当内核正在运行但系统流量未被接管（桌面端系统代理与 TUN 均关闭，或 Android 端 VPN 未开启）时，首页 Hero 状态区在提示当前状态的同时，提供一键开启接管的直接操作（桌面端可直达开启系统代理或 TUN，Android 端可直达开启 VPN），用户无需向下滚动查找开关或跳转设置页。
- 当首页打开「切换配置」弹窗（Profile Sheet）且存在多份配置时，提供名称/域名关键词筛选；订阅类配置支持在弹窗内直接触发刷新订阅，并展示内联更新中/成功/失败状态，无需退出弹窗前往配置页。

适用与失败边界：
- 适用于首页桌面端与移动端紧凑布局；未添加任何配置（欢迎态）时不展示未接管修复动作。
- 若开启系统代理/TUN/VPN 失败，保留原有未接管态并展示可读错误原因与重试/跳转设置的恢复路径，不产生假阳性已接管状态。
- 配置切换弹窗正在切换某份配置时，阻止并发切换与误关闭，刷新订阅失败时仅在对应条目展示失败原因与重试入口，不影响其他配置。

验收：
- 前置：内核已启动且桌面端系统代理与 TUN 均关闭；观察：首页 Hero 区域显示未接管提示及直接开启操作；触发开启后，接管状态立即更新，未接管警告消失。
- 前置：内核运行但开启接管操作返回错误；观察：Hero 仍明确表现为未接管态，并给出错误反馈与恢复入口。
- 前置：存在多份配置，用户点击首页配置胶囊打开切换弹窗；输入关键词后仅展示匹配配置，且可对订阅项直接触发更新并看到状态回显；清空关键词后恢复完整列表。

### R2 首页代理组置顶与节点选择器增强

行为：
- 首页代理组卡片支持将常用代理组置顶或取消置顶，置顶状态持久化保存至前端本地偏好；置顶的代理组优先排在首页代理组前排（不受默认折叠截取数量遮挡）。
- 从首页点击任意代理组打开的 `NodePickerModal` 支持：按默认顺序或延迟升序排序、切换「隐藏超时节点」筛选，以及对单个节点发起延迟测速并实时刷新该行延迟结果，避免用户在首页与代理页之间反复跳转。
- 假设：置顶代理组列表及节点选择器的排序/隐藏超时偏好保存在 `localStorage`；若存储不可用或数据损坏，降级为内存态默认值且不阻断交互。

适用与失败边界：
- 适用于首页展示的所有可交互代理组（含手动组与可固定自动组）及桌面/移动端视口。
- 当切换配置导致已置顶的代理组名称在新配置中不存在时，自动忽略失效名称，不出现空白占位或报错。
- 当内核未运行或离线时，节点选择器内的单节点测速与组测速保持禁用并给出清晰原因说明；当「隐藏超时」或搜索条件过滤掉全部节点时，展示空态与一键重置筛选操作。

验收：
- 前置：存在多个可手选代理组；输入：在首页将排在后面的代理组置顶并刷新页面；结果：该代理组位于首页代理组前排且刷新后仍保持置顶；取消置顶后恢复原顺序。
- 前置：已连接状态下在首页打开包含多个节点（含超时节点）的代理组弹窗；输入：切换按延迟排序、开启隐藏超时、点击单个节点测速；结果：列表按延迟重新排列、超时节点被隐藏、单节点展示测速中与测速结果，且选择节点后立即生效并关闭弹窗。
- 前置：未连接状态下打开节点选择器；观察：测速按钮禁用并展示离线提示，不触发无效请求。

### R3 代理页高频筛选与移动端模式切换

行为：
- 代理页工具栏在现有搜索、排序与「隐藏超时」基础上，提供低干扰的快捷筛选能力（支持按当前配置中实际存在的常用属性/协议标签或可用状态快速过滤，并与搜索词组合生效，且支持一键清空全部筛选）。
- 移动端（紧凑视口）代理页头部提供轻量出站模式切换（规则 / 全局 / 直连），与桌面端代理页保持能力对齐；当处于直连模式时仍保留醒目提示与一键切回规则模式。
- 桌面与移动端在未连接状态下保留顶部连接引导，并对组测速/节点测速的禁用态提供一致的语义提示。

适用与失败边界：
- 适用于代理页（`ProxiesView`）桌面端与移动端；当配置无代理组或全部代理组被标记为 `hidden` 时不显示筛选工具栏。
- 仅展示当前配置节点中真实存在的快捷筛选标签，不展示必然命中 0 条结果的空标签。
- 组合筛选无匹配节点时，展示明确空态与「重置筛选」按钮，点击后同时清空搜索词与快捷筛选状态。

验收：
- 前置：代理页存在含多种协议/标签（如 UDP、链式等）与超时状态的节点；输入：在工具栏点选快捷筛选并与搜索词组合；结果：仅显示同时满足条件的节点与代理组，计数与高亮准确；点击重置后恢复全部可见节点。
- 前置：紧凑（移动端）视口进入代理页且已启用配置；观察：页面头部可直接切换规则 / 全局 / 直连模式；切换后状态与首页及全局状态保持同步。
- 前置：组合筛选导致无匹配节点；点击空态中的重置按钮后，搜索词与筛选条件一并清空并恢复列表。

### R4 配置导入入口统一与批量更新反馈

行为：
- 统一全局「添加配置」弹窗（由侧栏/欢迎页/命令面板/托盘触发）与配置页内快捷导入栏的输入识别体验：当用户在全局「添加配置」弹窗中粘贴单节点分享链接（或支持识别的节点 URI）时，界面自动识别为节点链接并提供一键转入自建节点导入流程的引导，而非直接报无效订阅链接错误。
- 在配置页触发「更新全部订阅」时，在页面顶部呈现统一的批量更新进度与完成汇总（包含总数、成功数、失败数）；若存在失败项，提供「仅重试失败项」的直接操作，并与单张配置卡片的内联状态保持同步。

适用与失败边界：
- 适用于全局添加配置弹窗、配置页订阅标签与自建节点功能开启状态。
- 若用户已在设置中关闭「自建节点」功能，全局弹窗识别到节点链接时明确提示自建节点已关闭，并提供前往开启的快捷入口，而非静默失败或误启用。
- 批量更新期间重复点击全部更新不会并发重复触发；部分订阅失败时，已成功的订阅结果保留，重试仅针对失败项执行。

验收：
- 前置：自建节点功能开启，打开全局「添加配置」弹窗；输入：粘贴单节点分享链接；结果：界面识别出节点链接并提供一键转入自建节点导入，确认后预填内容并打开自建节点导入弹窗。
- 前置：自建节点功能关闭，在全局「添加配置」弹窗粘贴节点链接；结果：界面给出明确提示及开启引导，不产生模糊的网络下载报错。
- 前置：存在多份订阅配置且其中至少 1 份更新失败；输入：触发「更新全部订阅」；结果：顶部展示实时进度与最终成功/失败汇总，点击「重试失败项」仅重新请求失败的订阅并更新汇总状态。

### R5 全局壳层、命令面板与可交互 Toast

行为：
- 命令面板在搜索输入为空时，优先展示「最近使用」的高频动作（本地持久化）以及当前配置、主代理组的直达入口，减少输入成本；同时为移动端提供清晰可达的命令/全局搜索入口。
- 全局 Toast 反馈支持可选操作按钮（例如连接/切换/更新失败时附带「重试」或「查看日志」，导入成功后附带直达跳转），并对短时间内重复内容进行合并/去重及控制同时展示数量上限，避免遮挡界面或刷屏。
- 侧栏折叠态下保留清晰的当前连接态、模式与配置提示；页面切换与弹窗/抽屉过渡保持轻盈克制，并严格遵守系统 `prefers-reduced-motion` 偏好。
- 假设：命令面板「最近使用」列表以 `localStorage` 持久化，存储异常时降级为当前会话内存记录。

适用与失败边界：
- 适用于全局壳层（桌面侧栏、移动端紧凑壳层、命令面板与全局 Toast 队列）。
- 命令面板中仍严格排除破坏性/不可逆操作（如删除配置、清空日志等）；最近使用记录若对应动作当前不可用，仍按禁用态展示原因而不静默失效。
- 带操作按钮的 Toast 在用户悬停或聚焦按钮时暂停自动消失计时，点击操作按钮后执行动作并关闭对应 Toast。

验收：
- 前置：用户曾通过命令面板执行过动作后再次打开命令面板且未输入关键词；观察：空查询态展示「最近使用」及当前配置/主代理组快捷项；在紧凑（移动端）视口下也能从界面入口打开命令面板。
- 前置：触发带操作按钮的错误或结果 Toast（如操作失败附带「重试」或「查看日志」）；观察：Toast 展示可读文案与可点击按钮；连续触发相同内容的 Toast 不会无限堆叠；点击按钮后正确执行动作并关闭 Toast。
- 前置：系统开启减少动态效果偏好；观察：过渡动画降级为无位移/极简切换，功能不受影响。

### R6 视觉层级、布局一致性与边界态拉齐

行为：
- 围绕首页、代理页、配置页与全局壳层，统一卡片层级、标题与操作栏间距密度、图标与标签尺寸比例、按钮主次层级（primary / tonal / ghost / danger）及弹窗页眉页脚对齐。
- 统一所有交互控件的焦点环（`:focus-visible`）、悬停/按下反馈、移动端触控目标尺寸与禁用态原因提示；统一空态、加载态与超长配置名/节点名/中英文切换下的文本截断与换行表现，避免重叠、撑破容器或抖动。

适用与失败边界：
- 适用于首页、代理页、配置页、全局壳层及关联弹窗在桌面宽屏、桌面窄窗与移动端紧凑视口下的表现。
- 保持信息清晰与视觉克制，不因增加留白或装饰导致首屏关键信息（连接状态、当前节点、代理组列表）可视密度显著恶化。

验收：
- 前置：分别在桌面宽屏、窄窗与移动端紧凑视口下，使用超长配置名、超长节点名及中/英双语界面浏览首页、代理页、配置页与核心弹窗；观察：无文本溢出、按钮挤压换行错位、吸顶遮挡或焦点环缺失。
- 前置：以键盘 Tab/Shift+Tab/Esc 导航核心页面与弹窗；观察：焦点顺序连贯可见，关闭弹窗后焦点正确归位。

### R7 配色体系精调与色板一致性

行为：
- 在保留现有 6 套配色 ID（`teal` 碧潮、`sapphire` 晴空蓝、`indigo` 星夜靛、`terracotta` 暖砂陶、`berry` 绯莓、`graphite` 墨韵）不变的前提下，重新精调每套配色在浅色与深色模式下的色相、饱和度与明度层次：
  - 拉齐并优化页面底色（`--bg`）、侧栏/壳层（`--chrome`）、卡片表面（`--surface` / `--surface-2`）、下沉区（`--sunken`）与细边框（`--border` / `--border-input`）的柔和度与分层辨识度，避免高饱和刺眼或灰蒙失层。
  - 确保主色按钮、激活标签、选中节点、电源主控与 `--on-accent` 前景色在全部 6 套配色 × 明/暗模式下具备清晰可读的对比度（重点校准深色 `graphite` 墨韵及暖色系 `terracotta` / `berry` 的文字与边框对比）。
  - 协调 Hero 氛围光晕（`--hero-wash` / `--hero-stage-*`）、流量图双曲线数据色（`--data-down` / `--data-up`）与语义状态色（`--good` / `--fair` / `--poor`），使主色与延迟/成功/警告/错误状态色在视觉上易于区分且整体和谐。
- 校准设置页配色预览卡片（[GeneralPane.vue](file:///src/project/Billow/src/views/settings/GeneralPane.vue)）与窗口/系统栏 `theme-color` 元数据（[App.vue](file:///src/project/Billow/src/App.vue)），使其色值与实际 CSS 配色令牌保持单一事实来源或完全一致，消除预览与实装色差。

适用与失败边界：
- 适用于浅色、深色与跟随系统模式下的全部 6 套配色方案，以及桌面端与 Android 系统栏色同步。
- 已保存任意旧配色偏好的用户升级后平滑生效，不出现回退异常或未知配色错误；不因色板调整降低延迟色（绿/黄/红）与主色的语义区分度。

验收：
- 前置：依次切换 6 套配色 × 浅色/深色共 12 种组合；观察：首页 Hero、电源主控、代理选中节点、配置激活卡片、主按钮、禁用态、延迟标签与流量图在 12 种组合下均层次清晰、文字与图标对比明确、无色值冲突。
- 核对设置页配色预览卡所呈现的色板与切换后界面实际背景/侧栏/主色一致，且 `meta[name="theme-color"]` 随当前配色与明暗模式准确同步。

## 不做事项

### R8 明确排除范围

- 不修改 Rust 后端代码、Tauri IPC 命令签名、Mihomo 内核控制协议或持久化配色枚举 ID（不新增/删除配色 ID，不新增中途取消测速 IPC 或后端测速并发重构）。
- 不重构排障与非核心工具页（连接、规则、资源、日志、分应用代理及设置页除配色预览外的其他面板）的页面结构与业务流程（仅通过全局 CSS 令牌与壳层组件自然继承视觉与配色收益）。
- 不引入无信息价值的炫技动效、强玻璃拟态叠加或高噪点装饰元素，不牺牲列表渲染性能与信息可读性。

- [CommandPalette.vue](file:///src/project/Billow/src/components/CommandPalette.vue) 与 [store.ts](file:///src/project/Billow/src/lib/store.ts)：命令面板空查询行为、`Toast` 类型定义与 `ProfileRefreshProgress` 现状（支持 R4、R5）。
