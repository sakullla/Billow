# 需求：排障与可观测工具页深耕及规则穿透匹配

日期：2026-11-26

## 一屏摘要

面向 Billow 桌面端（Windows / macOS / Linux）与 Android 使用者，承接核心日常链路打磨成果，深耕「连接 / 规则 / 日志 / 外部资源」四大排障与可观测工具页，拉齐单行工具栏、高频筛选、移动端操作闭环与规则穿透诊断能力（R1–R5）。
- 连接页收拢桌面单行工具栏，补齐拦截（`REJECT`）、协议、活动传输及高频进程/主机速筛，完善移动端规则展示与卡片快捷操作（R1）。
- 规则页新增本地只读「规则匹配测试」（扩展只读 Rust IPC 穿透显式规则与已缓存 `MRS` / `YAML` / `Text` 规则集），并补齐移动端行级操作（R2）。
- 日志页升级大列表滚动渲染稳定性，优化窄窗级别筛选，新增「警告与错误」异常速筛、筛选态复制/导出语义区分及跨页排查入口（R3）。
- 外部资源页统一常驻搜索与状态筛选工具栏，补齐代理集「全部健康检查」、批量进度/失败重试闭环及详情弹窗渐进加载与单行复制（R4）。
- 打通四页跨页排障跳转与返回上下文，拉齐中英双语、键盘焦点环、移动端触控及 6 套配色 × 明暗表现；轻量前端偏好存 `localStorage` 并在不可用时降级为内存态默认值（R1、R5）。
- 排除项：不发起真实外部网络探测，不离线解析二进制 GEO 库（`GEOIP` / `GEOSITE` 按前置待核验诚实提示），不改动首页/代理/配置核心业务（R6）。
- 成功标准：R1–R5 全部关键行为、穿透匹配与失败边界满足可观察验收，且通过前端 Vitest 测试、TypeScript 构建与 Rust 单元测试校验。

## 完整需求

### R1 连接页单行工具栏、全分流筛选与高频维度速筛

行为：
- 桌面端连接页工具栏收拢为紧凑单行结构，搜索框在存在筛选条件时内聚显示匹配条数，并提供可折叠的快捷筛选抽屉/胶囊栏。
- 出站分流筛选在现有「全部 / 代理 / 直连」基础上补齐「拦截」（匹配 `REJECT`、`REJECT-DROP` 等拒绝出站），覆盖完整分流去向；快捷筛选支持按当前连接列表中实际存在的网络协议（`TCP` / `UDP`）、「活动传输中」（当前实时上下行速率非空闲）以及出现频次靠前的「高频进程 / 高频主机」一键点选过滤，并与搜索词组合生效及支持一键重置。
- 移动端（紧凑视口）连接卡片补充展示命中的规则摘要（规则类型与载荷），并提供单张连接卡片的快捷操作入口（对齐桌面右键菜单：查看详情、复制目标主机、按此主机/进程筛选、复制直连规则或写入当前配置覆写、前往代理组/查看规则集、断开活动连接）。
- 假设：连接页快捷筛选栏展开状态保存在 `localStorage`，存储不可用或异常时降级为当前会话内存默认值且不阻断筛选。

适用与失败边界：
- 适用于桌面端连接表格与移动端连接卡片（含「活动」与「已关闭」两个范围标签）。
- 切换至「已关闭」标签时，自动隐藏或禁用仅针对活动连接的「活动传输中」筛选项与「断开连接」操作，不产生误导或无效请求。
- 当平台不返回进程信息（如 Android 或进程字段为空）时不展示空的进程快捷标签；组合筛选无匹配连接时展示明确空态与「清空筛选」恢复按钮。

验收：
- 前置：已连接且存在走代理、直连与 `REJECT` 的 TCP/UDP 连接；输入：在桌面默认窗口宽度观察工具栏并依次点选「拦截」、「UDP」、「活动传输中」及高频进程/主机标签并与搜索词组合；结果：工具栏主行不断行，列表与匹配计数准确过滤，点击重置后恢复完整列表。
- 前置：切换至「已关闭」连接标签；观察：不展示活动传输筛选与断开按钮，已关闭记录仍可按出站类型、协议、主机/进程筛选与查看详情。
- 前置：紧凑（移动端）视口浏览连接列表；观察：卡片可见命中规则信息，触发卡片快捷操作可直接筛选同主机/进程、复制或写入直连覆写及跳转对应代理组或规则集。

### R2 规则页穿透匹配定位与移动端操作闭环

行为：
- 在规则页提供「规则匹配测试」能力：用户输入目标域名或 IPv4/IPv6 地址（并可选填写目标端口、进程名），前端调用新增的只读 Rust 诊断 IPC，按当前生效规则自上而下顺序做本地静态匹配评估。
- 匹配评估同时覆盖显式规则（`DOMAIN`、`DOMAIN-SUFFIX`、`DOMAIN-KEYWORD`、`DOMAIN-WILDCARD`、`DOMAIN-REGEX`、`IP-CIDR`、`IP-CIDR6`、`DST-PORT`、`PROCESS-NAME`、`PROCESS-PATH`、`MATCH` 等）以及本地已缓存可读的 `RULE-SET` 外部规则集（复用现有 `inline`、`YAML`、`Text` 与 `MRS` 二进制规则集解码能力），返回首条确认命中的规则行索引、出站策略及（若命中 `RULE-SET`）命中的具体子规则，并支持一键定位滚动并高亮对应规则行，或直达查看对应代理组/规则集。
- 收拢桌面端规则页单行工具栏（搜索框内聚匹配计数，窄窗不挤压换行），并为移动端规则行补齐快捷操作入口（对齐桌面右键菜单：复制规则表达式、按此规则类型/策略筛选、查看对应规则集、前往对应代理组、临时禁用或恢复启用）。

适用与失败边界：
- 适用于内核运行且已加载规则的桌面端与移动端规则页；内核未运行时禁用匹配测试并说明需先连接。
- 已被用户临时禁用的规则在匹配评估中自动跳过，若输入原本可匹配某条已禁用规则，结果中可附带说明其因临时禁用被跳过，最终命中落在后续生效规则上。
- 若在首条确认命中的规则之前，存在仅凭当前静态输入无法 100% 判定的前置规则（例如尚未下载或体积超限跳过读取的 `RULE-SET`、`GEOIP` / `GEOSITE` 规则，或用户输入纯域名而前置存在未带 `no-resolve` 的 `IP-CIDR` 规则），禁止伪装成绝对首条命中：必须同时展示「前置待核验规则列表及原因」与「后续首个静态确认命中项」，并提供前往外部资源更新/查看或打开 DNS 查询的辅助入口。
- 输入为空或格式非法时在输入框旁给出明确校验错误，不清空或破坏下方现有规则列表与筛选状态。

验收：
- 前置：内核运行，配置含显式域名/IP 规则、`MRS` / `YAML` 规则集及兜底 `MATCH`；输入：在规则匹配测试中输入命中某 `RULE-SET` 的子域名或网段内 IP；结果：准确显示命中的 `RULE-SET` 规则行、出站策略及规则集内命中的具体条目，点击定位后规则列表滚动并高亮该行。
- 前置：将原本命中的规则临时禁用后再次执行相同输入的匹配测试；结果：该已禁用规则被跳过，命中结果更新为下一条匹配规则。
- 前置：首条静态命中规则之前存在 `GEOSITE` 或尚未下载文件的 `RULE-SET`；输入：执行域名匹配测试；结果：界面明确提示前置存在待核验规则及具体原因，不产生假阳性唯一命中结论。
- 前置：紧凑（移动端）视口打开规则页；输入：触发任意规则行的快捷操作；结果：可完成复制、仅看同类型/同策略、跳转规则集或代理组以及临时禁启用操作。

### R3 日志页大数据量滚动稳定性、异常速筛与排障联动

行为：
- 升级日志页列表渲染与滚动机制：在最高 1000 条缓冲满载、高频追加、切换自动换行、切换搜索高亮及暂停/恢复场景下采用稳定的可视窗口渲染或等价高性能机制，消除大批量 DOM 同步重排卡顿与滚动跳动；用户主动上滚查阅历史日志时严守当前阅读位置，位于底部跟随态时平滑追尾。
- 优化桌面窄窗与移动端日志工具栏布局，消除带实时计数的 5 档级别切换在窄视口下的横向拥挤与截断，并提供一键聚焦「异常（警告 + 错误）」的快捷筛选能力。
- 明确筛选态下的复制与导出语义：当关键词或级别筛选生效时，操作提示与反馈清晰表明复制/导出的是「当前筛选匹配的 N 条日志」而非全部缓冲；单条日志除复制外，支持快捷操作以将日志中的目标词或报错线索带入日志筛选，或一键跳转至「连接 / 规则」页继续排查。

适用与失败边界：
- 适用于桌面端与移动端日志页；保留端口冲突与 TUN 冲突横幅直达对应设置项的能力。
- 暂停态下继续冻结当前可见列表与各级别统计计数，并准确提示后台新增条数与一键追平操作。
- 当当前筛选结果为空时，复制与导出按钮处于禁用态并给出明确不可用原因，空态提供一键清空筛选入口；日志导出失败时保留当前筛选与滚动位置并通过错误反馈说明原因。

验收：
- 前置：日志缓冲存在数百至 1000 条记录且持续追加；输入：上滚离开底部、切换自动换行与搜索关键词；结果：滚动条与视口位置稳定不跳回底部，点击「最新」浮标或恢复追尾后立即回到最新行。
- 前置：桌面窄窗与移动端视口浏览日志页并包含 `warning` 与 `error` 记录；输入：启用「异常（警告 + 错误）」筛选并点击复制；结果：工具栏无横向溢出裁切，列表仅显示警告与错误行，剪贴板内容及成功提示准确对应筛选后的行数。
- 前置：从某条含域名或规则线索的日志触发排障操作；结果：可将该线索带入日志搜索或跳转至连接/规则页对应搜索框。

### R4 外部资源页工具栏对齐、全量健康检查与详情渐进浏览

行为：
- 移除外部资源页「资源总数大于 8 才显示搜索框」的隐藏阈值：当配置存在外部资源（代理集或规则集）时，常驻展示统一的筛选工具栏，支持关键词搜索及按资源分类/状态（如「全部 / 代理集 / 规则集 / 更新或检查失败」）快速筛选，搜索框内聚显示匹配数并支持一键重置。
- 在代理集（`proxy-providers`）分组头部补齐「全部健康检查」批量操作（与「全部更新」并列），采用有界并发执行各代理集健康检查并实时刷新进度（`已完成/总数`）及节点延迟状态；代理集与规则集的批量操作完成后统一呈现清晰的结果反馈，若存在失败项则在分组头部与对应条目同步保留「重试失败项」入口。
- 在资源详情弹窗（`ProviderDetail`）中，当代理集节点或规则集规则条数超过首屏渲染上限（400 条）时，提供「显示更多」渐进展开按钮（直至后端预览上限），并为详情列表中的单条节点名或规则提供一键复制操作。

适用与失败边界：
- 适用于内核运行时的桌面端与移动端外部资源页；GEO 数据库卡片与设置弹窗保持现有下载源切换、单文件更新与错误恢复能力。
- 内联（`Inline`）规则集/代理集保持免更新标识，批量更新自动跳过内联项；代理集健康检查或资源更新进行中禁止对同一分组或同一条目重复并发触发；内核停止或切换配置时立即作废在途批次并清空旧配置状态。
- 对于总条数超过后端单次预览上限（5000 条）的超大型规则集，渐进加载至预览上限后明确提示总条数及「输入关键词可全量搜索整份规则集」，避免用户误以为仅有前 5000 条生效。

验收：
- 前置：当前配置仅含 2–4 个外部资源且其中 1 个更新失败；观察：搜索与状态筛选工具栏正常显示，点选失败筛选后仅展示异常资源，点击重置恢复全部。
- 前置：存在多个代理集；输入：点击代理集分组「全部健康检查」；结果：按钮展示实时完成进度，完成后各代理集状态与详情内节点延迟更新，若部分失败可直接点击「重试失败」仅对失败项重检。
- 前置：打开超过 400 条规则的规则集详情弹窗；输入：滚动至底部点击「显示更多」并点击某条规则的复制按钮；结果：列表追加展开后续规则且不卡顿，目标规则文本准确复制到剪贴板。

### R5 跨页排障上下文衔接与视觉无障碍一致性

行为：
- 打通「连接 ↔ 规则 ↔ 外部资源 ↔ 日志」四页的排障流转与返回闭环：从连接详情或快捷菜单除跳转代理组/规则集外，支持带目标主机/IP 跳转至规则页直接触发或预填「规则匹配测试」；从规则页（含匹配测试结果）查看规则集详情后支持一键返回原规则页上下文（保留原搜索词、筛选条件与测试结果），与现有的「返回连接」体验保持一致。
- 统一四大工具页在桌面宽屏、桌面窄窗与移动端紧凑视口下的标题栏、单行工具栏高度（与代理页/配置页一致的紧凑控件比例）、圆角层级、`:focus-visible` 键盘焦点环、移动端触控目标尺寸、中英双语文案（`zh-CN` / `en`）及超长主机名/规则载荷/文件路径截断表现；严格适配全部 6 套配色 × 浅色/深色共 12 种组合与 `prefers-reduced-motion`。

适用与失败边界：
- 适用于连接、规则、日志、外部资源四页及关联详情弹窗、上下文菜单与移动端底部操作面板。
- 跨页返回时若内核已断开或生效配置已变更，自动清理失效会话详情并给出平和清晰的状态说明，不展示跨配置脏数据。

验收：
- 前置：在连接页选中某条连接并选择前往规则页核验命中规则，再从命中规则打开对应规则集详情后逐级返回；观察：目标主机自动带入规则匹配测试并展示结果，从规则集返回规则页、再返回连接页时原筛选状态与上下文均准确恢复。
- 前置：切换中/英文界面、明/暗主题及不同配色方案，并在桌面窄窗与移动端视口下用键盘 Tab/Enter/Esc 与触控浏览四页；观察：无文本重叠、横向溢出、未翻译残留或焦点丢失。

## 不做事项

### R6 明确排除范围

- 不修改 Mihomo 内核自身源码或外部控制器协议，规则匹配测试保持客户端本地只读静态评估，不发起真实外部网络拨测请求，不产生额外代理流量。
- 不在本需求中实现 `Country.mmdb`、`GeoIP.dat`、`GeoSite.dat` 二进制 GEO 数据库的客户端离线解析引擎（配置中涉及 `GEOIP` / `GEOSITE` 的前置规则统一按 R2 作为待核验候选诚实提示）。
- 不改动首页、代理页、配置页的核心交互结构，也不纳入自建节点多协议表单、全量测速中途取消或 WebDAV 自动定时同步等独立主题。
