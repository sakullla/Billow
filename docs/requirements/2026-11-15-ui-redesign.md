# 修订：界面重做与功能补齐

日期：2026-11-15

本文件修订 `2026-11-14-mihomo-desktop-android-client.md`。原文与本文冲突时，以本文为准；未提到的条目（R1–R5、R7、R16、R21、R22 的行为与失败边界）保持不变。

## 原因

原版界面只有三个入口，诊断信息很少，跟 Clash Verge Rev、FlClash、Sparkle 等客户端相比功能差距过大。本次完全重做界面与交互，并补齐常用功能。

## 导航（替代 R17）

- 宽屏：侧栏，依次为 首页、代理、配置、连接、规则、日志、设置；侧栏底部显示连接状态与实时速率
- 窄屏 / Android：底部 5 项 首页、代理、配置、连接、设置；规则与日志从设置页进入
- 记住上次所在页面；旧值 `nodes` 映射到「代理」

## 首页（替代 R18–R20 的首页部分）

- 大号电源按钮 + 状态词 + 当前配置与端口；已连接时显示上下行速率
- 出站模式卡片（规则 / 全局 / 直连，带说明）
- 网络接管：桌面为系统代理与 TUN 开关；Android 为 VPN 开关与分应用代理
- 实时流量：最近 60 秒速率曲线、上下行速度、本次累计流量、活动连接数（取消 R18 中「不使用速率曲线」的限制）
- 当前节点：各手动代理组当前节点与延迟，点击跳到代理页对应组
- 订阅：流量进度条、到期日与剩余天数、更新时间、一键更新

## 代理页（扩展 R2）

- 全部测速（所有节点并发测试一次，结果写入包含该节点的每个组）、单组测速、单节点测速
- 组可折叠；显示组类型（手选 / 自动 / 故障转移 / 负载均衡）、当前节点、节点数
- 节点卡片显示协议类型与彩色延迟（失败显示「超时」文字）
- 自动组列出全部成员并标出当前节点，但不能手选
- 搜索、按默认 / 延迟 / 名称排序、隐藏自动组、紧凑视图；页内可切换出站模式

## 配置页（扩展 R1、R5）

- 卡片网格，当前配置置顶；点击卡片即启用
- 顶部快速导入链接；添加层支持订阅链接（含剪贴板粘贴）与本地文件（含拖放）
- 每份配置：更新、编辑信息（名称、订阅链接、自动更新间隔）、编辑配置文件（YAML）、覆写、复制链接、删除
- 全部更新；订阅可设置自动更新间隔（取消 R1 中「不包含无人值守定时更新」的限制）

## 连接、规则、日志（替代 R6、R12 的部分限制）

- 连接：表格（窄屏为卡片），显示主机、进程、规则、代理链、实时速度、累计上下行、时长；可搜索、排序、暂停；可断开单条或全部；点击查看详情
- 规则：读取运行中内核的规则列表，可搜索并按类型快速筛选
- 日志：增加调试级别；按级别筛选、搜索、暂停、复制、清空；保留「向上滚动时不拉回底部」

## 设置（新增）

- 外观：跟随系统 / 浅色 / 深色
- 启动与窗口（桌面）：开机自启、静默启动、关闭时最小化到托盘
- 内核：渠道、版本、检查更新
- 内核设置：混合端口、局域网连接、IPv6、统一延迟、TCP 并发、日志级别、进程匹配、测速地址与超时；不填则跟随配置文件；修改后运行中的内核自动重启
- 关于

## 托盘（新增，桌面）

托盘菜单：状态、打开主界面、连接 / 断开、系统代理、TUN、出站模式、退出。左键点击托盘图标打开主界面。

## 视觉（替代 R19）

保留：单一强调色、两层底色、浅深主题、系统字体、等宽数字、可见焦点、减少动态效果时停止装饰动画。
放宽：允许轻微阴影、强调色渐变用于品牌标识与流量进度条；延迟使用绿 / 黄 / 红三色，且始终带文字。

## 补充：TUN、DNS 覆写、外部资源（2026-11-15）

- **TUN 设置**（桌面）：协议栈 Mixed / gVisor / System、自动路由、自动选择出口网卡、严格路由、DNS 劫持、MTU、网卡名。始终写入运行配置的 `tun` 段（Android 使用 VPN fd，不写入）。
- **TUN 下的 DNS 兜底**：开启 TUN 而配置没有启用 `dns` 时，自动使用应用的 DNS 设置，避免 TUN 下域名无法解析。
- **DNS 覆写**：开关开启后，用应用的 DNS 设置替换每份配置的 `dns` 段。可设置增强模式（Fake-IP / Redir-Host / Normal）、Fake-IP 地址段与过滤名单、IPv6、hosts、respect-rules、主 / 引导 / 节点 / 直连 / 备用 DNS。
- **域名嗅探**：可覆盖配置，开启时写入默认的 HTTP / TLS / QUIC 嗅探。
- **缓存**：清除 FakeIP 缓存、清除 DNS 缓存。
- **外部资源**页：列出 proxy-providers 与 rule-providers（类型、行为、格式、数量、更新时间、代理集流量），支持单个 / 全部更新、代理集健康检查，以及更新 GEO 数据库。
- 设置页分为 通用 / 内核 / TUN / DNS 四栏；首页 TUN 行可直接跳到 TUN 设置。
