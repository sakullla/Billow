# 资源读取性能验证

2026-11-17，macOS Apple Silicon，Mihomo v1.19.34，Rust 优化构建。

本轮改动：

- MRS 位图直接借用解压后的字节，位索引从 `usize` 缩至 `u32`，只遍历置位位。
- 域名树遍历时直接把精确域名与子域模式合并为 `+.domain`，不再生成双份字符串后排序合并；最终顺序仍与 Mihomo 导出一致。
- 最近一个 MRS 文件的解码文本缓存在内存中，上限 8 MiB；路径、文件大小或修改时间变化时失效。缓存未命中串行解码，避免多个搜索同时展开规则集。保留全量计数和搜索，IPC 仍最多返回 5000 行。
- ASCII 规则搜索不再为每条规则分配小写字符串；非 ASCII 搜索保留 Unicode 大小写行为。
- GEO 下载通过 64 KiB 写缓冲流入临时文件，不再同时持有四份完整数据库；读完并验证体积后原子替换。代理失败回退、候选源重试、HTML 拒绝、128 MiB 单文件限制保持；下载中断保留旧数据库并删除临时文件。

合成样本含 200000 条 `+.d000000.example00.com` 风格的规则，由内置 Mihomo 转为 MRS。隔离解码进程的旧实现首次测得约 147 ms、58 MiB 峰值 RSS；优化后约 43–53 ms、25 MiB。旧实现后续耗时有较大波动，因此不把单次加速比例视为所有机器的保证。RSS 是隔离解码进程数据，不是 Billow 或 Mihomo 的整体内存。

发布优化构建的资源接口测试：首次预览 72 ms，返回前 5000 行并报告总数 200000；随后全量搜索末尾规则 `d199999` 用时 11 ms，未命中搜索 13 ms。此处包含文件读取、规则计数和过滤，不含前端 250 ms 输入防抖。

20 万条解码结果与改动前实现逐条一致。小型固定样本另与 Mihomo 导出比对，覆盖精确域名、子域、通配符、嵌套域名、中文和其他 Unicode 域名；IP 段原有测试继续通过。缓存替换失效、大小写搜索、GEO 下载中断及临时文件清理有回归测试。

可用私有本地 MRS 文件复测资源接口（不连接或修改运行中的内核）：

```sh
BILLOW_TEST_MRS=/absolute/path/to/rules.mrs cargo test --release \
  --manifest-path src-tauri/Cargo.toml --locked \
  benchmark_large_mrs_preview_and_search -- --ignored --nocapture
```

本轮降低的是客户端读取、预览和下载资源的成本；不改变 Mihomo 内部规则匹配或 GEO 加载算法。
