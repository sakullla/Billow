# 大屏缩放、资源页与离线启用

## 改动

- 桌面端按显示器逻辑尺寸自动设置 webview 缩放：短边 ≥1350 为 110%，≥1600 为 125%，≥2000 为 150%。窗口过小时降低缩放以保留桌面布局。首次在大屏启动时，默认 960×680 窗口按比例放大并居中。设置 › 外观可固定 90%–200%，⌘/Ctrl + = / - / 0 调整或恢复自动。新增权限：`core:window:allow-set-size`、`core:window:allow-center`、`core:webview:allow-set-webview-zoom`。
- 视口 ≥1640 / ≥2200px 时页面最大宽度放宽到 1400 / 1720px。
- 资源页：资源多于 8 个时显示名称筛选；代理集、规则集可收起，收起状态持久化；行更紧凑，宽区域排成 2–3 列；悬停才完全显示行内操作。
- 手机首页压缩主卡高度，让出站模式露在底栏上方；速率与运行信息改用比例字体的等宽数字；底栏上方内容渐隐。
- 启用（切换）已下载过的订阅直接使用本地缓存，不再联网；从未下载过的订阅仍会先下载。「更新」照旧联网。

## 验证

- 前端 `npm test`、`npm run build` 通过；新增缩放模块单测与资源页筛选/收起用例。
- Rust 新增 `enabling_a_downloaded_subscription_works_offline_and_only_update_fetches`：离线切换成功、不标记失败、不改更新时间；显式更新仍报下载失败。
- 浏览器预览检查了桌面资源页（16 个规则集）与 Android 首页、资源页。webview 缩放与首启窗口放大需在 Windows/macOS/Linux 的 2K/4K 屏实机确认。
