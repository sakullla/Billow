### 新功能

- **规则匹配测试与规则集穿透**：规则页新增规则匹配测试面板，支持输入域名、IP 或 `主机:端口` 只读核验最终命中规则与策略去向；支持穿透本地缓存的 `RULE-SET`（Inline / YAML / Text / MRS）展示具体命中子规则，并标注跳过的已禁用规则与前置不确定规则（如 `GEOIP` / `GEOSITE` / `PROCESS-NAME`），同时提供一键跳转至关联外部资源或 DNS 设置。
- **诊断四页跨页排障联动**：打通连接、日志、规则与外部资源页的排障链路，支持从连接条目、日志单行目标或规则匹配结果一键跳转核验与定位，并提供二级嵌套返回上下文（断连或切换配置时自动失效清理）。
- **外部资源批量健康检查**：代理集合新增批量健康检查与测速能力，并为同分组与单行刷新/检查补充并发互斥保护。

### 优化与调整

- **连接页四档分流与速筛收拢**：工具栏收拢为单行布局并新增「拒绝」分流筛选；可折叠速筛抽屉支持按协议、活跃状态及高频进程/主机快速过滤并记忆展开状态，同时补齐移动端规则摘要与行内操作菜单。
- **日志页动态虚拟列表与异常速筛**：接入动态行高虚拟列表以提升大流量日志滚动与追尾稳定性，新增「警告 + 错误」异常速筛、紧凑窄屏工具栏，以及按当前筛选态复制/导出计数反馈。
- **规则与外部资源页工具栏统一**：统一规则页与外部资源页的单行工具栏，移除外部资源搜索的条目数量阈值并新增状态与类型筛选；资源详情面板支持长列表渐进展开与一键复制。
- **界面细节与双语文案补全**：统一四个诊断工具页的控件比例、键盘焦点环、亮暗色对比度，并补齐新增交互的完整中英文文案。
