### 新功能

- **自建节点与链式代理**：在现有「配置」页内新增独立于机场订阅的自建节点管理（不新增一级菜单，纯机场用户零打扰），支持跨订阅持久化与本地 / WebDAV 备份恢复。
- **多协议节点录入**：原生支持批量粘贴 `vless://`、`vmess://`、`trojan://`、`ss://`、`hysteria2://`、`tuic://`、`anytls://`、`socks5://`、`http(s)://` 分享链接与 Base64 节点列表，提供 SOCKS5 / HTTP 快捷表单与单节点 YAML 兜底编辑。
- **可视化链式代理与一键开关**：支持将自建落地配置为「通过当前订阅中转」（自动生成无环前置组）、固定前置节点或自建多跳，带环路检测与前置缺失保护；机场订阅叠加支持随时一键关闭恢复纯净运行。
- **纯自建节点免写配置模式**：无机场订阅时可直接基于自建节点一键连接，自动使用内置分流规则实现国内直连、海外代理，无需手写 Mihomo YAML。
- **指定流量走落地**：免写 YAML 即可勾选 AI 服务等预设或添加自定义域名/后缀，仅将指定流量定向路由至干净 IP 落地。

### 优化与调整

- **备份与 WebDAV 交互升级**：WebDAV 连接可用时默认折叠账号密码表单为紧凑摘要条，将「上传备份」与云端列表前置到首屏；新增密码显隐切换与本地导出路径一键复制；云端备份列表优先展示来源设备名与「最新」徽标，移动端不再截断文件大小。
- **发布说明机制**：GitHub Release 与应用内更新提示改为优先展示面向用户的中文版本说明，缺失时自动按提交分类生成摘要。
