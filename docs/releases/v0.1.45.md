### 新功能

- **分享链接高阶参数全面补齐**：导入自建节点时，进一步对齐 Sub-Store / Mihomo 参数转换规范：
  - **VLESS**：支持透传非 `none` 的 `encryption`（兼容 Xray 后量子加密参数）与 `packet-encoding`（如 `xudp`）。
  - **传输层扩展**：支持 `xhttp` / `splithttp`（映射 `xhttp-opts`）、`httpupgrade`（映射 `ws-opts.v2ray-http-upgrade`），以及 WebSocket 路径中的 `?ed=2048` Early Data 自动拆解。
  - **Hysteria2**：新增 `hop-interval` 端口跳跃间隔映射，纯数字 `up` / `down` 速率自动补全 `Mbps` 单位。
  - **Shadowsocks 与证书指纹**：优化 `v2ray-plugin` / `shadow-tls` 插件的布尔与数字参数归一化，并为 VLESS / Trojan / AnyTLS 统一补齐证书指纹 `fingerprint`（`pinSHA256`）支持。
