### 问题修复

- **Android VPN 稳定性与异常恢复**：加固 Android 前台 VPN 服务生命周期（适配 Android 14+ 前台服务类型声明并避免系统探针误重建隧道），放宽切网与唤醒后的内核健康检查容错，提升移动端内存上限以减少 GC 卡顿触发的短暂掉线；支持内核意外退出后自动尝试恢复一次，并在 VPN 权限被收回、服务被系统停止或内核崩溃时统一写入日志，方便排查原因。
- **Android 局域网共享与热点 IP 识别**：修复 Android 已连接状态下切换「局域网连接」等内核设置未立即生效的问题；局域网地址检测优先识别手机热点与 Wi-Fi 网卡，避免开启个人热点时误显示运营商内网 IP 或空白。
- **资源页移动端搜索框与分组标题**：统一移动端资源页搜索框的高度与圆角样式，与连接、规则、日志和设置页保持一致，并修复窄屏下「代理集」「规则集」标题折行的问题。

### 优化与调整

- **局域网共享使用引导**：在「端口与网络 → 局域网共享」中新增「刷新地址」按钮与可展开的使用步骤（含手机热点共享配置说明与 Android 未 Root 设备的系统限制提示）。
